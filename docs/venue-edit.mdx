A venue is the location where events take place. Keeping venue information complete and accurate is important because the same venue can be used for many events. The information is reused throughout kulturbytes, for example on event and venue detail pages, maps and distance-based searches.

The venue editor is divided into four tabs.


## Basic information

The **Basic information** tab contains the main information about the venue. This includes the venue name, description, venue type, website and contact details, as well as the postal address.

The description can be formatted using **Markdown** and provides additional information about the venue. The website should contain the venue's official website and is used to provide a direct link for visitors.

You can also specify when a venue opened or closed. This can be useful for venues that are new, temporary or no longer operating.

A complete and accurate address is important because it helps visitors identify the venue and provides a reliable basis for its geographical position and map display.


## Map

For information about setting the geographical position and the relationship between the address and the map position, see the [Maps](/maps) page.


## Logos

Here you can upload logo images for your venue. For information about logo formats, recommended dimensions, different logo variants and their uses, see the [Logos](/logos) page.


## Images

The **Images** tab allows you to add photographs of the venue. You can provide a **main photo** and up to three additional **gallery photos**.

The main photo is used as the primary image for the venue, while the gallery photos can provide additional views or show different areas of the venue. Good venue images can help visitors recognise the location and get a better impression of it before attending an event.

For general information about image formats, recommended dimensions, cropping, accessibility and image properties, see the [Images](/images) page.

When adding images, consider accessibility as well. Provide meaningful **alt text** where an image conveys relevant information, and use the image properties to add information such as the photographer, copyright and licence where applicable.
