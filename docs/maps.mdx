The **geographical position** shows exactly where an organization or venue is located.

It is important so that kulturbytes can display the organization or venue on a **map**. The position can also be used when searching for events in the surrounding area and when calculating distances.

Set the position as accurately as possible on the building or the actual location of the organization or venue.

The address and geographical position are connected:

* The **address** describes the location as text.
* The **geographical position** shows the location on the map.
