Dashboard giver dig et overblik over dine data og deres aktuelle status. Det viser, om dine data er klar til offentliggørelse eller kræver yderligere arbejde.

Brug Dashboard som dit udgangspunkt, når du har logget ind. Herfra kan du gå til det relevante afsnit og opdatere dine data.
