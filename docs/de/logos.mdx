Logos helfen Besuchern, eine Organization oder einen Ort wiederzuerkennen, und ermöglichen kulturbytes eine einheitliche Darstellung in verschiedenen Zusammenhängen.

Allgemeine Informationen zu Bildformaten, Abmessungen, Zuschnitten, Barrierefreiheit und weiteren Bildeigenschaften findest du auf der Seite [Bilder](/images).

## Bild hochladen [#image-upload]

Achte beim Hochladen von Logos auf eine ausreichende Bildqualität. Wir empfehlen eine Breite von etwa **960 Pixeln**. Das bietet genug Auflösung für verschiedene digitale Anwendungen bei einer angemessenen Dateigröße.

Verwende möglichst **PNG-Bilder mit transparentem Hintergrund**, besonders für Logos, die auf verschiedenen Hintergründen angezeigt werden sollen.

## Hauptlogo [#main-logo]

Das **Hauptlogo** ist das Standardlogo deiner Organization oder deines Ortes.

Es wird verwendet, wenn das Logo auf einem hellen Hintergrund angezeigt wird.

Verwende möglichst eine Version mit transparentem Hintergrund.

## Helles Logo [#light-logo]

Das **helle Logo** ist eine helle Variante deines Logos.

Es eignet sich für **dunkle Hintergründe**. Zum Beispiel kann ein weißes Logo auf einem dunklen Hintergrund gut sichtbar sein.

## Dunkles Logo [#dark-logo]

Das **dunkle Logo** ist eine dunkle Variante deines Logos.

Es eignet sich für **helle Hintergründe**.

Wenn du verschiedene Logoversionen bereitstellst, kann kulturbytes das passende Bild für unterschiedliche Hintergründe und Darstellungen auswählen.

## Avatar [#avatar]

Der **Avatar** ist eine vereinfachte oder quadratische Darstellung deiner Organization oder deines Ortes.

Er wird dort verwendet, wo nur wenig Platz für ein Bild vorhanden ist, zum Beispiel in Listen, kleinen Profilbildern oder Übersichten.

Gut geeignet sind häufig:

* das Symbol aus deinem Logo
* ein charakteristisches Symbol deiner Organization oder deines Ortes
* ein quadratischer Ausschnitt deines Logos

## Tipp [#tip]

Wenn du mehrere Logoversionen hast, lade möglichst alle geeigneten Varianten hoch. So kann kulturbytes für verschiedene Hintergründe und Darstellungen das passende Bild verwenden.
